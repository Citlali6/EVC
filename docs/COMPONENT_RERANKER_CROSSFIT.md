# Running the train-only component reranker cross-fit

The experiment definition is frozen in
`docs/COMPONENT_RERANKER_CROSSFIT_PROTOCOL.md`.  This utility is CPU-only and
consumes the strict `event_count > 30000` train cache.  It does not accept a
validation path.  Do not describe its held-block result as an unbiased
independent OOF estimate: each held train block also selects its candidate.
The value of the design is cross-source consistency under a fully
preregistered train-only gate.

The cache must be generated by the current cache builder.  Older caches that
do not contain the independently verified all-99 official source-manifest
digest are rejected rather than silently upgraded.  The exact selected
population is 54 videos / 8,555,762 events (`000-014`, `028-032`, `040-047`,
`059-065`, `067-074`, `088-098`).
Cross-fit additionally requires the released M20 checkpoint SHA-256
`4b8b2b19ea9d913ee4e52cb21ae52bf945b2b0f3cefd5cb5ab6f64d51bf49849`;
the generic cache builder may create other caches, but this protocol will not
accept them.

same M20 inference settings.

Preregister before inspecting any cross-fit result:

```powershell
$Args = @(
  'crossfit_component_reranker.py', 'preregister'
  '--cache-dir', '<NEW_AUDIT_DIR>\train_cache_gt30000'
  '--config', 'configs\evisseg_evuav.yaml'
  '--output-protocol', '<NEW_AUDIT_DIR>\crossfit_protocol.json'
  '--expected-selected-videos', '54'
)
foreach ($item in $C00) { $Args += @('--override', $item) }
& 'C:\Users\CSK\.conda\envs\yolo\python.exe' @Args
```

Record the printed protocol-file SHA-256 outside the result report.  Then run
exactly that protocol:

```powershell
& 'C:\Users\CSK\.conda\envs\yolo\python.exe' crossfit_component_reranker.py run `
  --protocol '<NEW_AUDIT_DIR>\crossfit_protocol.json' `
  --expected-protocol-sha256 '<RECORDED_64_HEX_SHA256>' `
  --cache-dir '<NEW_AUDIT_DIR>\train_cache_gt30000' `
  --output-report '<NEW_AUDIT_DIR>\crossfit_report.json' `
  --output-model '<NEW_AUDIT_DIR>\component_reranker_full54.json'
```

The report is always written after a successful run.  The model path remains
absent when any gate fails.  If report publication fails after a passing run,
the tool removes the just-written artifact so that an unaudited model is not
left behind.  Even a passing artifact remains default-off until a separate,
explicit validation replay is authorized.
