### 3.1 真实训练证据

- 上述实验均生成了 epoch checkpoint；新式窄 scope checkpoint 同时保存 optimizer、scheduler、RNG、resolved config、初始化 checkpoint 摘要和 Git provenance。
- Attention projection、DACC-v2、H17 和 confidence-only 的 optimizer 分别只包含预注册的 `9,312 / 32 / 17 / 2,353` 个参数。
- Attention projection 三轮 optimizer step 为 `108 / 216 / 324`；sparse 分支也完成相同的 324 次真实更新。
- 窄 scope 的非目标 state tensor 通过进程内快照或 checkpoint 后验比较保持逐位不变；这排除了“声称冻结但实际更新了其他层”的情况。
- DACC-v2 的零投影 identity checkpoint 严格复现基线；训练后的最佳 Score 低于基线，因此没有把 identity 结果算作训练提升。

## 4. 负结果与机制判断

### 4.1 全量续训没有保住 M20

M21 是最直接的全量续训控制组，最佳 Score 已下降 `6.54e-4`，Pd 从 `0.9762704746` 降到 `0.9745905082`。M22 的密度视图重分配、M23 的指标辅助损失、M24/M24b 的 coverage 和 M25 的 memory-only 均没有超过 M20。由此不能把“继续训练更多 epoch”视为可靠方向。

### 4.2 小参数校准没有产生正收益

- 低 LR 的 H17 BCE/coverage 与基线同分，说明 17 参数确实发生了训练，但没有改变最终离散决策。
- 将 H17 LR 提高 10 倍后，BCE 分支下降；`.95` coverage 分支前两轮下降，第三轮仅回到基线。
- DACC-v2 的 32 参数残差投影训练后下降约 `6.03e-5`。
- Confidence-only 虽降低 Fa，但 IoU、Acc 和 Pd 损失更大，最终下降约 `9.25e-4`。

### 4.3 Attention 不是“没有训练”

标准 attention-projection 三轮与基线同分，但参数并非未更新：最终 output projection 相对 M20 的总位移 L2 为约 `0.002141`，约为原 projection L2 的 `25.6%`。它只是没有跨过固定评估链路的离散决策边界。

Sparse sampler 改变了梯度方向而非简单放大标准更新：

- Sparse E1 projection 位移 L2 为 `0.001763`，standard E1 为 `0.001283`，前者是后者的 `1.374` 倍。
- 两者 E1 参数位移方向余弦仅 `0.127`。
- Sparse 三轮 Score 为 `0.9628195217 / 0.9628105751 / 0.9628105751`；Pd 和 Fa 不变，IoU/Acc 下降。

高密度 attention expert 也完成了真实训练，而不是只生成了文件：

- 训练集严格使用 `event_count > 100000` 的 15 个视频，每视频 8 views，共 `120 step/epoch × 3 = 360` step。
- optimizer 只包含 attention output projection 的 2 个 tensor、9,312 个参数；其余 1,915,404 个参数冻结。checkpoint 中 optimizer step 为 `120 / 240 / 360`，Adam moments 均有限。
- 冻结 state SHA 为 `78e659e275d7351e040bfd65c89b63459cd6c66f4da5393918fa5f618e9c5190`；逐 tensor 审计未发现 projection 之外的变化。
- E1/E2/E3 的 projection weight 位移 L2 为 `0.002622 / 0.003565 / 0.003839`，证明 360 步产生了实质参数更新。
- 固定事件数路由回放的 E1/E2/E3 Score 为 `0.9628195217 / 0.9628105751 / 0.9628687135`，三轮均低于 M20 `0.9628776542`。

因此，标准、sparse 和 high-density expert 三种 attention-projection 路线都没有正收益；没有证据支持盲目提高 sparse LR 或直接解冻全部 attention 参数。

### 4.4 阈值搜索没有发现合法提升

在固定 M20 raw cache 上，对高密度阈值做了 101 点细扫。最优仍是发布阈值 `0.719`，Score `0.9628776542`；没有阈值超过基线。

预注册的五折嵌套 cross-fit 中，modal threshold 为 `0.719`，5 折中选中 4 次；另一折选中 `0.7248`。OOF Score 为 `0.9627784875`，相对基线 `-0.0000991667`，并且预注册晋级门未通过，因此 `promoted_for_hidden_test = false`。该搜索结果只作为稳定性审计，不作为新的提交方案。

## 6. 漏检与假警的结构

### 6.1 Pd miss 集中在稀疏目标与轨迹边缘

- 113 个 Pd miss 中，84 个目标组的 raw 最大分数低于对应阈值；另 29 个虽有 raw 分数越过阈值，但被后处理移除；没有 miss 的 raw 最大分数达到 `0.95`。
- low 层 miss 中 95.2% 的目标组只有 1–3 个正事件；middle 层为 100%。high 层 miss 的正事件支持数中位数为 4.5，而 hit 中位数为 11。
- 精确落在每条 target track 首/末 bin 的 miss 率为 `29/156 = 18.6%`；距离边缘不超过 2 bin 时为 `60/462 = 13.0%`；距离边缘大于 5 bin 的内部区域仅 `32/3861 = 0.83%`。
- miss 的轨迹边缘距离中位数为 2，hit 为 23。

这些证据解释了 sparse-target-support sampler 的设计动机，但该 sampler 与 BCE-only attention projection 的实测结果仍然下降，不能仅凭机制合理性宣称有效。

### 6.2 假分量多数很小

1,584 个假分量中有 1,218 个是单事件分量，占 `76.9%`。按密度层统计，单事件占比分别约为 low 72%、middle 81%、high 76%。这说明假警抑制仍有空间，但 confidence-only 的真实实验表明，简单全局置信度校准会同时损伤 Pd、IoU 和 Acc。

## 9. 反作弊与可复现说明

本轮实验遵守以下约束：

1. **真实训练。** 每个训练实验保存 epoch checkpoint、真实 optimizer step 和非空 Adam moments；不通过伪造 loss、epoch、参数或手工修改 checkpoint 制造结果。
2. **训练/验证隔离。** 模型梯度只使用官方 train 标签。val 标签仅用于固定评估、误差诊断和明确标注的阈值稳定性审计，不进入训练反向传播。
3. **固定链路。** 所有正式 checkpoint 使用相同的 M10/M20 路由、阈值、P0/P0c/P18 和 24 文件验证身份；失败模型不允许通过重新调阈值“救分”。
4. **无文件名特判。** 推理路由只能依赖事件数等预注册输入属性，不使用 `val_015`、`val_023` 等文件名或验证标签制定规则。
5. **严格加载。** 推理和 resume 路径使用 strict checkpoint 校验；DACC-v2 的唯一初始化迁移也明确审计 missing/unexpected keys 和继承 tensor 的逐位一致性。
6. **冻结范围可验证。** H17、DACC-v2 和 attention-projection 等窄 scope 记录明确 mutable keys、参数量和 frozen-state SHA；非目标 state 的变化会使实验失败。
7. **原始证据保留。** 每个实验保存在独立目录，包含 config、training log、checkpoint、评估 CSV/JSON、代码/数据/checkpoint 摘要；不覆盖 M20 基线。
8. **不把验证集搜索包装成提升。** 101 点阈值细扫和五折 cross-fit 均原样记录负结果，未通过门禁就不形成 hidden-test 或提交候选。
9. **探索结果不冒充 golden。** C09 虽在同一 24-val 上数值更高，但未达到结果生成前写明的 `+0.0001` 门槛；报告保留其完整正负变化，并明确 `promotion_gate_passed = false`。
